# Assets cho Website Wedding

## Cách sử dụng jsDelivr CDN

### URL Pattern:
```
https://cdn.jsdelivr.net/gh/kientrinh24-05/weeding-myself@main/assets/images/[filename]
```

### Ví dụ:
- Upload file: `assets/images/wedding-photo.jpg`
- URL CDN: `https://cdn.jsdelivr.net/gh/kientrinh24-05/weeding-myself@main/assets/images/wedding-photo.jpg`

### Lưu ý:
1. Commit và push file lên GitHub trước
2. Có thể mất 5-10 phút để jsDelivr cache file mới
3. Sử dụng tag version thay vì `@main` để cache lâu dài

### Purge cache (nếu cần):
https://purge.jsdelivr.net/gh/kientrinh24-05/weeding-myself@main/assets/images/[filename]
